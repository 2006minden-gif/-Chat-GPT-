Работа продолжается от931e111 без замены архитектуры. Одна общая приёмка после реализации; обязательные CI/защиты выпуска сохраняются.

- [x] Контекст обращения → заказ/бриф/оценка/документы/банк/приглашение/результат (PR50–52); ручные решения сохранены.
- [x] Автоматические приглашения после проверенной оплаты, безопасные повторы/неопределённый SMTP, без публичной регистрации (PR51).
- [x] Шесть отдельных DOCX/PDF, приватные копии/проверка, ручные чеки (PR49); одобрения владельца не подделываются.
- [ ] Выпустить поддержку: договорные даты, отдельный срок рабочего доступа, предупреждения/удержания, несколько заказов и приватный архив.
- [ ] Выпустить реальные черновики четырёх существующих услуг и конкретный проект политики/согласия для ручной проверки.
- [ ] Завершить удобное редактирование графиков и связанных коммерческих условий без технических ID.
- [ ] Выпустить публичное портфолио/отзывы, браузерный редактор/медиа, отдельные добровольные разрешения и модерацию точного содержания.
- [ ] Выпустить размещённый MAX mini-app с проверкой подписи, защищённой привязкой аккаунта и общим платёжным ограничением.
- [ ] Выпустить контекстную помощь по реальным экранам.
- [ ] Единая итоговая приёмка сайта, кабинета, поддержки/архива, публикаций и входа MAX после реализации и необходимых реальных настроек.

Единые зависимости владельца: достоверные недостающие реквизиты; проверка/одобрение конкретных юридических версий и шаблонов; фактическая настройка URL mini-app в MAX. Подтверждение почты сохранено. Отсутствие этих решений не останавливает независимую реализацию; закрытые возможности не объявляются активными.
